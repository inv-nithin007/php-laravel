## Step-by-Step Instructions

### Backend Setup:
1. Open terminal
2. Navigate to project directory: `cd /home/nithinkrishna/school-m`
3. Start Laravel server: `/opt/lampp/bin/php artisan serve --host=127.0.0.1 --port=8000`
4. Keep this terminal open - Backend will run on http://127.0.0.1:8000

### Frontend Setup:
1. Open a NEW terminal (don't close the backend terminal)
2. Navigate to React directory: `cd /home/nithinkrishna/school-m/REACT`
3. Start React development server: `npm run dev`
4. Frontend will run on http://localhost:5173 (or similar port shown in terminal)

### Access the Application:
- **Frontend URL**: http://localhost:5173 (check terminal for exact port)
- **Admin Login**: 
  - Username: `admin`
  - Password: `admin123`

### Troubleshooting:

**If Backend fails to start:**
- Check if XAMPP is running: `/opt/lampp/lampp status`
- Start XAMPP if needed: `sudo /opt/lampp/lampp start`
- Make sure MySQL is running for database connection

**If Frontend fails to start:**
- Make sure you're in the REACT directory
- Run `npm install` if packages are missing
- Check if port 5173 is already in use

**Database Connection Issues:**
- Ensure XAMPP MySQL is running
- Database name: `school_management`
- All tables should be created automatically

### Important Notes:
- Always start Backend FIRST, then Frontend
- Keep both terminals open while using the application
- Use XAMPP's PHP (`/opt/lampp/bin/php`) not system PHP
- Backend runs on port 8000, Frontend on port 5173 (usually)

### Database Overview:
- **Database Name:** `school_management`
- **Tables Created:**
  - ✅ **users** - Main authentication table (id, username, email, password, role, status)
  - ✅ **teachers** - Teacher profiles (user_id, first_name, last_name, employee_id, subject_specialization, etc.)
  - ✅ **students** - Student profiles (user_id, first_name, last_name, roll_number, class_grade, assigned_teacher_id, etc.)
  - ✅ **migrations** - Laravel migration tracking

### Database Relationships:
- **teachers.user_id** → **users.id** (Foreign Key)
- **students.user_id** → **users.id** (Foreign Key)  
- **students.assigned_teacher_id** → **teachers.id** (Foreign Key)

### What You'll See:
1. **Professional database structure** with proper relationships
2. **Foreign key constraints** ensuring data integrity
3. **Laravel migration system** for version control
4. **Clean table design** following database best practices
5. **Empty tables** ready for data (use Laravel API to populate)

### Database Features:
- **Role-based access:** admin, teacher, student
- **Unique constraints:** usernames, emails, employee IDs, roll numbers
- **Proper data types:** bigint for IDs, varchar for text, date for dates, enum for status
- **Laravel timestamps:** created_at, updated_at on all tables
- **Cascade deletes:** User deletion removes associated teacher/student records
